# The pre-call brief

One page. Mike reads it in the two minutes before he dials. If it runs longer
than a page it has failed, because it will not get read.

## Sources, in order of authority

1. **Corrections Mike gives** on a prior draft of this brief
2. **What Mike says about the client** in the conversation asking for it
3. **The Zoho deal record**, which is the system of record for the numbers
4. **The drip log**, which holds the touch that booked this call and the
   number it carried
5. **The SMM record**, for enrollment status and the monitoring figures

Where they conflict, higher wins, and say in the brief that they conflicted.
A silent reconciliation is how a wrong number reaches a client.

## Never invent

The rule from the lender notes skill applies here without softening. A short
brief with named gaps beats a complete looking brief with one invented figure.

- Never infer a maturity date, a balance, a rate, or a payment
- Never estimate a property value unless a source provides it, and say which
  source, because a stale valuation and a fresh one lead to different advice
- Never guess what the incumbent has offered. If it is not known, that is the
  first triage question, not a brief line
- Never state an equity figure built on an assumed value
- Never write "TBD". Either the figure is there with its source, or the line
  says plainly that it is not known and Mike needs to ask

## Output shape

```
RENEWAL BRIEF, [client name]
[day, date, time], 45 minutes, Mike calls

THEY ARE HOLDING
[the exact number from the drip touch that booked this call, and which touch
it was, and when it went out]

POSITION
Lender, current rate, balance, payment, maturity date, remaining
amortization, property value with its source and date, equity.
Any line not known is written as not known, with what to ask.

THE MATH
What renewal at the incumbent's likely offer costs over the term.
What the alternative costs over the same term.
The difference in the same units the drip used.
Penalty exposure if leaving early is on the table, with which formula applies.

TRIAGE READ
Which branch this most likely is, in one or two sentences, and why.
This is a read, not a conclusion. The five triage questions decide it.

FIVE BESIDE RATE
The five, pre-filled with what is known about this client, blank where it is
not. The blanks are the questions worth asking.

BRANCH PROMPTS
A, switch has value: the gate line and what comes next
B, incumbent wins: the coaching line and the monitoring close
C, no mortgage to renew: the short path

GAPS
Everything the record did not have, listed plainly.

COMPLIANCE
Fresh transaction under FSRA if this advances. What rides the path.
Monitoring enrollment status, and whether consent is on file.
```

## The number that opens the call

Find the drip touch that booked this session and carry its figure forward
unchanged. Name the touch, for example T-60, and the date it sent, so Mike
knows how old the number is.

If the touch's number is now stale because rates moved, say both: what the
client was shown, and what it is now. Do not silently replace it. Mike needs
to know the gap exists before the client points it out.

If the booking cannot be traced to a touch, say so. A client who booked from
a hand sent link or an inbound call is holding a different context, and Mike
should know he is opening cold rather than on a number.

## Length discipline

If the record is thin, the brief is short. Three known figures and four named
gaps is a legitimate brief and an honest one. Padding it with generic renewal
commentary makes it longer and less useful, and it teaches Mike to skim, which
is how the one line that mattered gets missed.
