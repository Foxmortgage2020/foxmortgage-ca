# A-06: Codex skills as a marketing team
source: Codex__Build_Your_Full_AI_Marketing_Team__Agents___Skills__mp3.txt
context: Filename guess confirmed. Creator with 1.5M followers demos seven Codex marketing skills. He sells a skills library and a new hosted agent product. Nationality never stated, not a mortgage professional.

## Big idea
An agent is only as good as what you point it at, so the work is reusable instruction files grounded in your own material.

## Patterns
- GROUNDING: task → pull exemplar transcripts, imitate voice and structure → draft. Default taste is the vendor's, not yours.
- SECOND BRAIN MINING: saved items → weekly commonality pass → ranked ideas with source links. Material already filtered by your judgment.
- SKILL SELF-EDIT: noticed defect → agent amends its own instruction file → later runs carry the fix. One correction becomes standing memory.
- PROMOTE TO SCHEDULE: run by hand, iterate, then convert to a recurring job. Only proven workflows get automated.
- TRIAGE TO TABLE: inbox and calendar → filter, dedupe, score fit → ranked table with suggested times → human approves before any send. Filtering was the cost.
- SHARED MINI APP: one API surface for agent and human → agent bulk-generates options → human finishes. Same tools, two operators.

## Human-in-the-loop
- Approval before any brand email or booked call.
- Mid-run steering: screenshot the bad output, inject a fix while it runs.
- "I want to take it the final 10%."
- The one automated job writes a document, not a send.
