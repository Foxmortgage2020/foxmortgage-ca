# A-09: Free Claude Code sales skills, five parallel agents
source: I_Built_An__80K_Sales_Rep_With_Claude_Code___It_s_FREE_mp3.txt
context: Manifest guess holds. Creator gives a GitHub skill pack away free and sells a five-week paid community on starting an AI agency. Nationality never stated, not identifiably Canadian.

## Big idea
A prospect brief that took a rep hours collapses into one command when every research question gets its own parallel agent.

## Patterns
- RESEARCH FAN-OUT: one identifier to five concurrent sub-agents (profile, people, score, rivals, approach) to one brief. Each agent owns one question, so nothing queues.
- SKILL AS INSTRUCTION FILE: a markdown file per task to a slash command to repeatable output. The file is the expertise.
- FIT SCORE WITH PUBLISHED METHOD: research to a 0-100 score with printed breakdown and methodology. A visible method makes the number arguable.
- STAKEHOLDER MAP: org research to roles labelled economic buyer, champion, evaluator, blocker. Names who to open on.
- PERSONAL ANCHOR HARVEST: per-person posts, talks and projects to one reference each. Openers stop reading as templates.
- CADENCED SEQUENCE: brief to day 1 hook, day 3 value, day 7 proof, day 21 close-out. Each message has one job.

## Human-in-the-loop
- None stated. Presented as one prompt, no review step.
- Two unacknowledged gates: permission prompts before fetching, and drafts carrying unfilled placeholders.
- Nothing verifies a named person, title, or cited post before send.

## Stack mentioned
Claude Code, VS Code, GitHub repo, PDF script. Replaces Apollo, ZoomInfo, Outreach, Sales Navigator. Fox equivalents: existing skills, Zoho COQL for the book, native render engine for the PDF, Radar queue, n8n for sends.

## Claims
- Reps cost 50 to 80 thousand a year, rival tools hundreds monthly [self-reported, sells a paid agency community].
- Two to three hours of daily work down to under two minutes [self-reported, same incentive].
- Loom scored 75 of 100, high priority [self-reported, unverified].

## Failure modes
- Terminal output was "a little hard to read", so a PDF step was added.
- Every draft email carries bracketed placeholders a human must fill.
- No breakage admitted anywhere, which is itself the flag.

## Compliance flags
- Cold email to strangers is CASL territory with no consent basis.
- Third-party PII into an agent with no retention rule.
- Agent-asserted org charts go unverified, so a wrong name reaches a real inbox.
- FSRA: a generated mortgage message is presenting, which stays with Mike.

## Fox fit
Cold-only, park it, for the prospecting and outreach half. The primitives transfer: a fan-out producing one scored page from a client's own file is the Prep a call shape, and the day-offset cadence fits RENEW and POST-FUND where consent exists.
