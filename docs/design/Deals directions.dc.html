1eRationale
What this direction optimizes
Reading speed and calm. Every row answers where the file is and what to click in one left to right sweep, and the one lime button is the loudest thing on the screen. At eighty files the ledger just gets longer, nothing changes shape.
What it trades away
Phase geography. A glyph and a word carry position, and the board view carries the map. If a new agent thinks in lanes first, direction 2 will orient them faster.

1jRationale and the type question
What this direction optimizes
Orientation. The spine answers where every file sits before a single row is read, and its counts stay honest at eight files or eighty. Mono refs and money line up so columns scan vertically.
What it trades away
Quiet. Navy chrome and two type families cost some calm, and the spine spends ninety vertical pixels before the first row.
On type
IBM Plex was drawn for enterprise tooling and its mono sibling was built for tabular data, so it reads more institutional than Archivo to me. Both work with this direction. The same row in each:
